PWMS Users API — User Guide

Read-only parliamentary user register · API v1 · for approved partner applications

Before you start

Your PWMS administrator gives you:

  • the base address, e.g. https://workflows-dev.parliament.gov.za
  • a client ID and client secret
  • the users:read scope

Keep the secret private. If it is exposed, ask for it to be rotated. The API is read-only: you cannot create, edit or deactivate users. Interactive documentation: /api/v1/docs.

1. Get an access token

POST /api/v1/auth/token/
curl -s -X POST "$BASE/api/v1/auth/token/" \
  -H "Content-Type: application/json" \
  -d '{"client_id":"YOUR_ID","client_secret":"YOUR_SECRET"}'

The response contains access_token, refresh_token, expires_in (900 seconds) and refresh_expires_in (86400 seconds).

  • Access token: 15 minutes. Send it as Authorization: Bearer <token> on every call.
  • Refresh token: 24 hours, single use. Exchange it at POST /api/v1/auth/token/refresh/ with {"refresh_token":"…"} to get a new pair.
  • On 401, refresh (or obtain a new pair), then retry once.

2. Endpoints

Method and pathWhat it returns
GET /api/v1/users/ List, search and filter users
GET /api/v1/users/{public_id}/ One user by their UUID
GET /api/v1/search/ Combined search; use resources=users
GET /api/v1/me/ Your client ID and scopes (not a person)

Every request needs Authorization: Bearer <access_token>.

3. Filters

ParameterUse
search Case-insensitive substring across all searchable fields
search_fields Comma-separated subset of the searchable fields (below)
is_active true / false
is_mp true / false — Members of Parliament
is_staff_member true / false — staff members
department Group UUID, name, short name or slug
ordering last_name (default), first_name, username, date_joined; prefix with - to reverse
limit / offset Page size (default 20, max 100) / records to skip

Searchable fields: username, first_name, middle_name, last_name, email, positiondesc, department, constituency, party_affiliation, phone.

4. Example requests

# Active Members of Parliament, by surname
curl -sG "$BASE/api/v1/users/" \
  -H "Authorization: Bearer $TOKEN" \
  --data-urlencode "is_active=true" \
  --data-urlencode "is_mp=true" \
  --data-urlencode "ordering=last_name"

# Search by first and last name
curl -sG "$BASE/api/v1/users/" \
  -H "Authorization: Bearer $TOKEN" \
  --data-urlencode "search=Alice Molefe" \
  --data-urlencode "search_fields=first_name,last_name"

# Users in a department
curl -sG "$BASE/api/v1/users/" \
  -H "Authorization: Bearer $TOKEN" \
  --data-urlencode "department=Portfolio Committee on Health"

# One user
curl -s "$BASE/api/v1/users/PUBLIC_ID/" \
  -H "Authorization: Bearer $TOKEN"

Use curl -G --data-urlencode (or your library's query parameters) for names with spaces or punctuation.

5. Pages and fields

A list response is a page with count, limit, offset, next, previous and results. Follow next until it is null; the links keep your search and filters.

Each user includes public_id, username, title, first_name, middle_name, last_name, display_name, email, employee_type, positiondesc, department, supervisor, is_active, is_mp, is_staff_member, constituency, party_affiliation and phone.

department is a nested object with public_id, name, short_name and group_type. supervisor is a nested object with public_id, username and display_name; it is null when no manager is recorded, and the supervisor's own manager is not expanded.

Identity numbers, date of birth, gender, bio/avatar and the list of direct reports are deliberately not exposed.

6. Common responses

StatusMeaning and action
200Success
400Invalid parameter; correct the request
401Missing/expired token; refresh or get a new pair
403Key lacks users:read; contact the administrator
404No user with that public_id
429Rate limit; wait for Retry-After, then retry

7. Practical tips

  • Refresh before the 15-minute access token expires; handle 401 once.
  • Send booleans as true / false, e.g. is_mp=true.
  • Use the public_id, not an internal ID or a username, as the stable identifier.
  • Request only the page size you need; 20–50 keeps responses fast.
  • Each key has a requests-per-minute limit (60 by default; your registration may differ).
  • The token endpoint is limited to 20 requests per minute per IP address.
  • Contact the PWMS administrator if a person is missing or you need another scope.
