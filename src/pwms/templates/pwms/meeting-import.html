Upload a .csv or .xlsx file of meetings. Each row creates a meeting, or — when its Reference already exists — updates that meeting. A blank cell leaves the field untouched, a row that cannot be read is reported and skipped (the rest of the file still imports), and nothing is ever deleted or emailed. The columns are the same ones the calendar exports, so an exported file can be edited and imported straight back.
