{% comment %} A meeting's minutes: the current status, the filed minutes documents, and the actions that move the status on (draft / filed / approved). "Upload minutes" opens the shared SharePoint picker aimed at the meeting with the attachment type defaulted to *Minutes* (the picker lives in the Attachments tab), and switches the reader to that tab so the upload is visible. The tab is switched through Bootstrap's Tab API on the real tab button — ``data-bs-toggle`` only works on an element inside the tab list, and on a button elsewhere it resolves a null parent and throws. Rendered standalone as the HTMX response to a status change and included by ``pwms/meeting-detail.html`` for the first paint. Context (see ``pwms.views._meeting_minutes_context``): meeting, minutes_attachments, agenda_attachments, can_edit_minutes, minutes_status_message (optional: {level, message}). {% endcomment %}
