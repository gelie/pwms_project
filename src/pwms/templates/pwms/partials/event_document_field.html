{% comment %} The Events tab's document field: an editable URL plus a SharePoint browser that fills it with a document chosen from the user's sites. A bill's browser opens on its dedicated B-number folder; every other record starts from the sites the user belongs to. Uploading a local file stores it in SharePoint and puts its link in the field, so an event can cite a document that is not attached to the record itself.
