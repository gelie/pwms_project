{% comment %} Bootstrap pagination for a browsable list. Expects ``page_obj`` (a Django Page), ``page_range`` (the page numbers to offer, computed in the view because templates cannot pass arguments to a method) and ``base_query`` (the page's current filters, urlencoded, with no ``page`` parameter). Page links append ``page=N`` to ``base_query``, so moving page keeps the filters. ``aria_label`` is optional.
