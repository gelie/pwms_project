{% comment %} The BR03 update history on a delegation report: the updates recorded against it, the form that records another, and — in the header — how many there are. Recording an update that carries any ATC detail (reference, publication date, page or document) emits the ``atc-update-published`` event, which is the evidence the *Close – House approved* transition is guarded by (see ``pwms.models.DelegationReportUpdate``). This is therefore the screen that unblocks closing a report; an update without ATC detail is still recorded, it just publishes nothing. Rendered standalone as the HTMX response to a create, and included by ``pwms/delegation-report-detail.html``. The response root and the include target are both ``#report-updates-section``; callers swap it with ``outerHTML``, and the status alert lives outside it in the tab pane so it survives that swap. Context (from ``pwms.views._updates_context``): report, updates, can_edit_updates, update_form; plus updates_status ({level, message}) when one was just recorded. {% endcomment %}
