{% comment %} The domain-event log on a workflow detail page: the events recorded against the record and the form that records one. Events are append-only rows (``pwms.WorkflowEvent``) typed by the ``EventType`` registry, so there is no edit or delete here — a correction is recorded as a new compensating event. Unlike a note, an event is evidence: it can guard a transition, and it feeds the merged Timeline tab. Rendered standalone as the HTMX response to a record, and included by ``pwms/workflow-detail.html`` for the first paint. The response root is ``#events-section`` and callers swap it with ``outerHTML``; the status alert lives outside it (in the tab pane) so it survives that swap. The tab's own Events counter is refreshed out-of-band when the fragment is rendered for an HTMX request, since it is in the tab bar rather than the panel. Context (from ``pwms.views._events_context``): event_rows, can_record_event, event_form, target_content_type, target_object_id; plus events_status ({level, message}) when an event was just recorded. {% endcomment %}
