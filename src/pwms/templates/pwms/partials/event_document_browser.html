{% comment %} The SharePoint browser for an event's document field, swapped into ``#event-document-browser`` by the "Browse SharePoint" button. Left: a lazily expanded tree of the user's sites, drives and folders. Right: the documents in the selected folder, each with a "Use this document" action, and an upload that stores a local file in that folder. A bill's folder opens by default; another workflow type opens on its configured folder when there is one.
