What are Workflow States?

States represent the different stages a workflow can go through during its lifecycle. Examples include "Draft", "Under Review", "Approved", "Rejected", etc.

Initial State

Each workflow type must have one initial state. When a new workflow is created, it automatically starts in this state.

Order

The order field helps organize states logically. This is especially useful for reporting and displaying workflow progress.

Note: After configuring states, you can define transitions that control how workflows move between these states.
