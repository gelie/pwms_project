{% lucide "circle-help" class="w-5 h-5" %} About Workflow Transitions

What are Workflow Transitions?

Transitions define how workflows can move from one state to another. Each transition specifies a source state, destination state, and which roles can execute it.

Required Roles

Each transition can specify which user roles are required to execute it. Only users with these roles can perform the transition.

Workflow Flow

Transitions create the workflow process flow. By defining which states can transition to others, you control the complete lifecycle of a workflow.

Note: Make sure you have configured states before creating transitions. Each transition must connect two existing states.
